B2CB0KP0Caractéristiques : Boîtes de vitesses
1. Boîte de vitesses mécanique
1.1. Généralités
Le véhicule est équipé d’une boîte de vitesses mécanique à 5 rapports.
Selon la motorisation, le type de boîte est le suivant :
  • Boîte de vitesses BE3/5 pour la motorisation XU10J2C
  • Boîte de vitesses ME5K pour la motorisation XU10J2CTE
Les boîtes de vitesses sont équipées d’un frein de marche arrière.

2. Commande de changement de vitesses
2.1. Généralités
La commande de changement de vitesses est une commande à câble (non réglable).
Le levier de vitesses est situé en partie centrale de la planche de bord.
