C4BT04P0Évolution : Gâches de hayon
DEPUIS OPR 7829
1. Véhicule concerné
CITROËN EVASION .
2. Application
Depuis le numéro DAM 7829.
NOTA : DAM = numéro Début d’Application de Modification.
Nouvelles gâches de hayon et nouveau cache gâches de hayon.
3. Présentation
Figure : c5dq009d
A : Ancienne pièce.
B : Nouvelle pièce.
4. Intervention
4.1. Opérations préliminaires
Déposer :
  • Les garnitures de plancher arrière
  • Les gâches de hayon
  • Les protecteurs de butées latérales
Vérifier la planéité des appuis de gâches, débosseler si nécessaire.
4.2. Pose
Poser les nouvelles gâches de hayon.
Figure : c5dq00ac
Positionner l’excentrique des butées latérales (gauche et droite) sur le 5ème trait en partant du bas (mettre le repère à l’horizontale).
Fermer le hayon et vérifier l’affleurement (hayon/aile 0 +1 mm).
Si l’affleurement n’est pas correct, modifier légèrement la position des gâches de hayon.
Poser les nouveaux cache gâches de hayon.
4.3. Opérations complémentaires
Reposer :
  • Les protecteurs de butées latérales
  • Les garnitures de plancher arrière
NOTA : Effectuer plusieurs essais de fonctionnement.
